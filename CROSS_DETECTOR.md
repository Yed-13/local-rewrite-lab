For reference, the previously measured GPTZero Human probabilities for the reviewed C1/C2/C3 versions selected here were 75% / 44% / 90%, respectively. Their GPTZero originals had Human probability 0%. The third reviewed version is direct mode; the first two use own-style context.

The large GPTZero improvements did not transfer in this set of additional checks. ZeroGPT, QuillBot and Pangram indicators rose. Sapling stayed at approximately 100%, with no substantive improvement. This adds evidence about detector-specific behavior rather than support for a general detector-bypass claim.

在这批文本中，GPTZero 上的明显改善未迁移到其他检测器。ZeroGPT、QuillBot、Pangram 的 AI 指标上升；Sapling 仍接近 100%。本轮结果支持分析不同检测器的判定差异。

## Metrics and versions / 指标与版本

ZeroGPT's displayed metric is `AI GPT*`; no model version was shown. Its result text remained “AI/GPT Generated” or “Likely generated by AI/GPT” for these pairs.

Sapling's displayed metric is `AI-detection score`. Version 1.3.3 was observed in captured analysis responses for C2 and C3; the first pair's visible result did not show a version. The free interface's length conditions led to using corresponding complete paragraph groups of 1,009–1,505 characters, rather than submitting full documents and accepting truncation. These are separate paragraph-level checks, not full-document replications.

QuillBot returned model version `v7.1.0`, model ID `ai-detector-en-1.0.2`. The table uses its actual browser-request response field `aiScore × 100`, consistently for originals and rewrites. Rounded UI displays and AI-generated / AI-refined / Human-written categories are separate fields. An early UI number-animation frame was excluded from measurement in favor of the saved completed model response.

Pangram displayed model 4.1 and “of this text is AI.” Both C1 results were described as mainly AI with some human-written content. Its available anonymous credits allowed one full-document pair; 19 existing free credits were consumed, with one left. No paid upgrade was purchased.

## Method and access / 流程与使用条件

The three complete-document pairs use the same extraction format and retained end matter as the earlier GPTZero comparison. Sapling pairs contain corresponding complete paragraph groups with the same source claims. Inputs were checked against the editor before submission. Completed responses and visible results were saved locally; report text was also compared with the intended source where the interface echoed it.

Ad-covered clicks, input mismatches and old-report states were resolved and excluded from valid scans. No CAPTCHA was bypassed, new account created or paid detector credit purchased. QuillBot's existing account initialization was completed by the account owner before scanning.

This round contains 20 valid scans across 10 paired comparisons, including six paragraph-level and fourteen full-document scans. [Native result data](evidence/cross_detector_results.csv) includes scope, metric, score, version, timestamp and input length. Full private texts and raw responses are not distributed.
